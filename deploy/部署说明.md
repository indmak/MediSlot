# MediSlot 云端部署说明（宝塔面板）

## 服务器信息

| 项 | 值 |
|----|----|
| 域名 | `medi.goposy.com` |
| 站点目录 | `/www/wwwroot/medi.goposy.com` |
| 面板 | 宝塔面板（仅用于域名绑定 / 文件管理 / SSL / 反向代理） |
| 运行方式 | 网站程序在 Docker 中运行，应用 + 数据库各一个容器 |
| 应用对外端口 | 宝塔 Nginx 反代 → `127.0.0.1:8080`（不直接暴露 8080） |
| 数据库端口 | 不映射到宿主机，仅容器网络内可访问 |
| 密钥注入 | 挂载文件 `./secrets` → `/run/secrets`，**不走环境变量** |

## 架构

```
                ┌────────────────── 宝塔面板 ──────────────────┐
 用户 ── 443 ──▶│ Nginx(站点 medi.goposy.com)  反向代理 + SSL  │
 (HTTPS)        └───────────────┬──────────────────────────────┘
                                │ http://127.0.0.1:8080
                     ┌──────────▼──────────┐        ┌──────────────────┐
                     │  medislot-app        │──3306─▶│  medislot-db     │
                     │  (Spring Boot 容器)  │ 内网   │  (MySQL 8.4 容器)│
                     └─────────────────────┘        └────────┬─────────┘
                                                              │
                                                    ./data/mysql (持久化)
                     ./secrets ──(ro 挂载)──▶ /run/secrets（密码/API 密钥）
```

## 一、首次部署

### 1. 获取代码

```bash
cd /www/wwwroot/medi.goposy.com
# 首次：git clone 或上传仓库；已接入 git 则：
git pull
```

### 2. 准备密钥文件（不进环境变量）

密钥以文件形式挂载，`docker inspect` 看不到。详见 `secrets/README.md`。

```bash
cd /www/wwwroot/medi.goposy.com
mkdir -p secrets/medislot/external/deepseek

# 生成强密码（注意：不要带换行）
printf '%s' "$(openssl rand -base64 24 | tr -d '/+=' | cut -c1-24)" > secrets/db_root_password
printf '%s' "$(openssl rand -base64 24 | tr -d '/+=' | cut -c1-24)" > secrets/db_password
# 未来接入 DeepSeek 时再填：
# printf '%s' 'sk-xxxx' > secrets/medislot/external/deepseek/apikey

chmod 700 secrets
find secrets -type f -exec chmod 600 {} \;

# 应用容器以非 root 用户运行（uid 1001），需让其能读取；root 仍可读，其他用户不可
# 查看 uid：docker run --rm --entrypoint id medislot-app:latest
chown -R 1001:1001 secrets
```

非密钥项（可覆盖，均有默认值）放在 `.env.prod`（可选）：`DB_USER`、`APP_PORT`。

### 3. 构建并启动

```bash
cd /www/wwwroot/medi.goposy.com
docker compose -f docker-compose.prod.yml up -d --build

# 查看日志（等待出现 "Started MediSlotApplication"）
docker compose -f docker-compose.prod.yml logs -f app
```

> 首次构建在容器内用 Maven 打包（已配置阿里云镜像加速），约 3–8 分钟。
> MySQL 首次启动读取 `secrets/db_root_password`、`secrets/db_password` 初始化。

### 4. 配置宝塔站点

1. **域名绑定**：网站 → 添加站点，域名 `medi.goposy.com`，PHP 版本选「纯静态」。
2. **反向代理**：站点设置 → 反向代理 → 目标 URL `http://127.0.0.1:8080`，
   或直接采用 `deploy/nginx-medi.goposy.com.conf` 的配置。
3. **SSL**：站点设置 → SSL → Let's Encrypt 申请证书，开启「强制 HTTPS」。

完成后访问 `https://medi.goposy.com` 即可。

> 云端 docker profile 默认写入演示数据（5 科室 / 5 医生 / 1 患者）与内置管理员，
> 仅在数据库为空时写入一次。如需关闭：设 `MEDISLOT_SEED_ENABLED=false`。

## 二、更新代码后重新部署

```bash
cd /www/wwwroot/medi.goposy.com
git pull
docker compose -f docker-compose.prod.yml up -d --build app
```

> 面板「容器编排」的按钮（重启/重建）也走同一份 compose；compose 已给 `DB_USER`/`APP_PORT`
> 默认值，因此即使面板不带 `.env` 也能正常启动。

## 三、停止 / 清理

```bash
# 停止（保留数据）
docker compose -f docker-compose.prod.yml down

# 停止并删除数据（慎用，会清空 MySQL）
docker compose -f docker-compose.prod.yml down -v
rm -rf ./data/mysql
```

## 四、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 构建时拉取 Docker 镜像超时 | 服务器访问 Docker Hub 不稳定 | 面板 → Docker → 配置 → 添加镜像加速，或为 daemon 配代理 |
| Maven 依赖下载慢 | 未走国内镜像 | 已内置 `apps/backend/docker/maven-settings.xml`（阿里云） |
| 应用启动报 Connection refused | MySQL 未就绪 | `depends_on: condition: service_healthy` 已处理，别删健康检查 |
| 应用启动报 `${db_password}` 无法解析 | 缺 `secrets/db_password` | 按第 2 步创建密钥文件 |
| 8080 已被占用 | 宿主机有别的服务 | 改 `APP_PORT`（`.env.prod` 或 compose 默认），同步改 Nginx 反代地址 |
| 打不开、502 | 应用没起来 | `docker compose ... logs -f app`；确认 `127.0.0.1:8080` 可访问 |
| 数据重启后丢失 | 用了 `down -v` | `down` 不删数据，`down -v` 才删 |
| 改了 `secrets/db_password` 但登录失败 | MySQL 密码仅首次初始化时生效 | 同步改数据库用户密码，或从空数据目录重来 |

## 五、安全清单

- [ ] 密钥放在 `secrets/`（挂载文件），未提交 Git、权限 `600`
- [ ] `.env.prod` 不含密码，且未提交
- [ ] 数据库不映射宿主机端口
- [ ] 应用仅绑定 `127.0.0.1:8080`
- [ ] 站点已开启 HTTPS 且强制跳转
- [ ] 宝塔面板开启「安全入口」+ 面板端口放行范围限制 + 面板 SSL
- [ ] 高价值密钥（如 DeepSeek）：轮换方便、必要时改用外部密钥管理（Vault 等）
